MOVEUP Screen Time — TWORAPPS support website

1. Create a PUBLIC GitHub repository named moveup-support.
2. Upload index.html, style.css, privacy.html, terms.html and sv.html to the repository root (not a subfolder).
3. Open repository Settings > Pages > Build and deployment > Deploy from a branch.
4. Select main and /(root), then Save.
5. Wait for GitHub Pages to publish.

Your URLs will be:
https://YOUR-USERNAME.github.io/moveup-support/
https://YOUR-USERNAME.github.io/moveup-support/privacy.html
https://YOUR-USERNAME.github.io/moveup-support/terms.html

Use the first URL for App Store Connect Support URL and the second for Privacy Policy URL.

IMPORTANT BEFORE APP STORE SUBMISSION:
Review the privacy policy against the FINAL RELEASED SOURCE CODE, including camera processing, storage, analytics, any data sharing, and deletion requests. Review terms and subscription behavior too. The draft is intentionally transparent about details still requiring confirmation. Replace provisional statements with verified factual disclosures before submitting. Confirm the contact email is monitored.
